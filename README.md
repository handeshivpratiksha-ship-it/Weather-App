# 🌤️ Weather App

A simple and responsive weather application that lets you check current weather conditions and a 5-day forecast for cities around the world.

## ✨ Features

- 🌡️ Current temperature
- 💧 Humidity
- 💨 Wind speed
- 🌡️ Feels-like temperature
- 📅 5-day weather forecast
- 🎨 Dynamic weather backgrounds
- 🌙 Automatic Day/Night mode
- 📍 Use My Location
- ⏳ Loading state
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Vercel
